## Latest
- [Geometry Transmitter](geometry-transmitter.md) — 2026-08-18: new `GeoTx` harness outlet, the geometry twin of Text Transmitter. Load-bearing discovery: `SetPersistentData(params object[])` can only make ONE flat branch, so a tree is internalized by reflecting to the target's constructed `GH_PersistentParam<T>` and casting each item with its protected `Cast_Object`. Change key is **reference identity** of the goo (can over-send, can never miss); the solve's tree must be COPIED before the idle write. Shared half extracted to `ParamTargets`.
- [Tool image attachments](tool-image-attachments.md) — 2026-08-18: new `take_snapshot` tool (camera at a point, aims over the full sphere, hands back a photo). Needed a new pipeline path: **a tool result is TEXT on every provider**, so an image rides the same answering user turn as an ATTACHMENT, ordered AFTER every `ToolResultContent` (Anthropic requires those to lead). It was being dropped in TWO silent places — `Router.CollectResults` and `ConversationLogBuilder.RecordToolSignal`. No provider change needed.
- [Move In Space tool](move-in-space-tool.md) — 2026-08-17: new `move_in_space` LLM tool. Adjacency is DERIVED (8 in-plane cones × 3 vertical bands, closest-per-bucket) — that one rule makes a step a step AND resolves "up a level" to the next level, so the Z-clustering I started writing was dead code. World-frame directions, not heading-relative. New `LlmToolComponentBase` hooks: `RegisterAdditionalOutputs` + `OnSolveEnd` (publish a call-mutated output there, NOT `OnSolveTick`, which runs before the calls).
- [Harness sub-document](harness-subdocument.md) — 2026-08-17: **the residency guard is GONE** — Physalia components may be placed bare on the canvas again (`HarnessResidency` + its `PhyBase.AddedToDocument` hook deleted). Nothing else needed repairing: every harness-keyed path was already nullable. The one thing that actually broke was the transmitter drag arrow, restored by the new `OutletArrowAttrib` — one attribute reading residency LIVE, because attributes exist before the component reaches a document.
- [Harness sub-document](harness-subdocument.md) — 2026-08-17: **"Load Harness from .gh File…"** — the reverse of Save-as-Preset, on the same two menus, reading ANY `.gh` and REPLACING the harness's contents. The lesson is the teardown: a discarded sub-document must be `RemoveObjects` + `Dispose`d or its `RemovedFromDocument`s never run and the warm CLI sessions / host-doc subscriptions leak — and the swap must ADOPT FIRST, so whatever reacts to the teardown already sees the replacement.
- [Feedback turn attribution](feedback-turn-attribution.md) — 2026-08-17: pink feedback turns are now **collapsed by default** behind a header wearing the producing component's icon + nickname. Needed new `PhySignal.Origins` **provenance** (not a carrier field) because every aggregator re-mints under its own identity and erased the producer; `MergeIntoLastUserMessage` also stopped silently dropping `IsFeedback`.
- [Group-scoped grounding](group-scoped-grounding.md) — 2026-08-17: the master group is now **per harness (`"Physalia <8 hex of harness guid>"`)**, since two group-grounded harnesses used to lock onto the same group and export each other's work; identity threads through the whole façade as `HarnessComponent?`. Same day: the CompTx **drag-out** creates the master "Physalia" group (holding a light robin-egg-blue hint panel, excluded from exports like the group itself), and **group ↔ harness-proxy movement is now mutual, without the proxy being a group member** — GH raises no "moved" event, so it is a throttled idle poll for a rigid delta (`MasterGroupFollower`), where the anti-runaway trick is re-measuring after a carry.
- [Merge Signal join](merge-signal-join.md) — **2026-08-17 fix:** a merged Geometry Report + Geometry Observation reached the model as the IMAGE ALONE. Aggregating by "join the payloads, concatenate the blocks" breaks the invariant that a signal's `ContentBlocks` are the WHOLE turn, so the Conversation Log recorded the blocks and dropped the report. New Core `SignalAggregation` (shared with the Feedback Collector, which had the same bug) promotes a text-only part's payload to a `TextContent` block. 2026-08-16: the component itself — a **JOIN, not a passthrough** (parallel branches latch on separate scheduled solves, so per-solve merging would emit once per branch); variable inputs append/remove at the **END only**, because the hold and the base's consume-once `_marks` are index-keyed.
- [Codex dynamic tools](codex-dynamic-tools.md) — 2026-08-16: Codex can call Physalia's LLM Tools with **zero canvas changes** — `dynamicTools` declared at thread start, the call DEFERRED back to the Router (never executed in-turn), session stays warm so results return as a plain delta. The load-bearing fix: drop all text after a tool call, because `turn/interrupt` loses the race and the model's apology would otherwise become the assistant turn.
